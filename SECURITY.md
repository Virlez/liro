# Signaler un problème de sécurité

Merci de ne pas publier de secret, de contenu de page ou de donnée personnelle dans une issue.

Pour un problème de sécurité, contactez le mainteneur en privé via l’adresse associée au dépôt GitHub. Décrivez le navigateur, la version de Liro, les étapes minimales de reproduction et l’impact observé. Les captures doivent être anonymisées.

Liro ne doit contenir aucun token, certificat privé, fichier `.env`, URL personnelle ou texte utilisateur dans le dépôt. Les sorties de build et les rapports de test sont ignorés par Git.
